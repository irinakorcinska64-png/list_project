

# Простий калькулятор

Консольний калькулятор для виконання базових арифметичних операцій. Навчальний проєкт для вивчення Python та GitHub.

## Функціональність

- Додавання чисел.
- Віднімання чисел.
- Множення чисел.
- Ділення чисел.
- Піднесення до степеня.
- Обчислення остачі від ділення.

## Інструкції з встановлення

1. Завантажити репозиторій.
2. Відкрити папку проєкту.
3. Запустити програму командою:

```bash
python calculator.py
```

## Приклад використання

```python
a = 15
b = 7

result = a + b
print(result)  # Результат: 22
```
