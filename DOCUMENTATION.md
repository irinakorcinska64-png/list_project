
# Документація API

## Модуль Calculator

### Функція add()

**Опис:** Додає два числа.

**Параметри:**
- `a` (float) — перше число.
- `b` (float) — друге число.

**Повертає:** Суму двох чисел.

**Приклад:**
```python
result = add(5, 3)
print(result)  # 8
```

### Функція subtract()

**Опис:** Віднімає друге число від першого.

**Параметри:**
- `a` (float) — перше число.
- `b` (float) — друге число.

**Повертає:** Різницю двох чисел.

**Приклад:**
```python
result = subtract(5, 3)
print(result)  # 2
```

### Функція multiply()

**Опис:** Множить два числа.

**Параметри:**
- `a` (float) — перше число.
- `b` (float) — друге число.

**Повертає:** Добуток двох чисел.

**Приклад:**
```python
result = multiply(5, 3)
print(result)  # 15
```

### Функція divide()

**Опис:** Ділить перше число на друге.

**Параметри:**
- `a` (float) — перше число.
- `b` (float) — друге число.

**Повертає:** Результат ділення або повідомлення про помилку при діленні на нуль.

**Приклад:**
```python
result = divide(10, 2)
print(result)  # 5
```

### Функція power()

**Опис:** Підносить число до степеня.

**Параметри:**
- `a` (float) — основа степеня.
- `b` (float) — показник степеня.

**Повертає:** Результат піднесення до степеня.

**Приклад:**
```python
result = power(2, 3)
print(result)  # 8
```

### Функція modulo()

**Опис:** Обчислює остачу від ділення.

**Параметри:**
- `a` (float) — перше число.
- `b` (float) — друге число.

**Повертає:** Остачу від ділення.

**Приклад:**
```python
result = modulo(10, 3)
print(result)  # 1
```
